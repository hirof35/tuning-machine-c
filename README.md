Minimal Turing Machine Simulator (C Language)
計算機科学の基礎である「チューリングマシン」の動作をC言語でシミュレートしたプログラムです。有限状態オートマトンと、無限（本プログラムでは有限）の長さを持つテープ、そしてテープ上を移動するヘッドという抽象的な計算モデルを具現化しています。

🧠 プログラムの論理構造
本プログラムは、特定のアルゴリズム（例：入力の最初の'1'を'x'に置換して右端へ移動する）を実行するように構成されています。

Tape (テープ): TAPE_SIZE（100）のメモリ領域。初期値は _（空白）で満たされます。

Head (ヘッド): 現在読み書きしている位置を指すインデックス。

State (状態遷移):

State 0: 開始状態。'1'を見つけると'x'に書き換え、State 1へ遷移してヘッドを右に移動させます。それ以外の場合は停止します。

State 1: 右移動状態。テープの空白（_）に到達するまでヘッドを右へ動かし続け、到達したら停止（HALTED）します。

🛠 技術的特徴
構造体によるカプセル化:

TuringMachine 構造体により、テープ、ヘッド、状態を一つのユニットとして管理。マシンの「現在のコンテキスト」を明確に保持しています。

決定性状態遷移:

step 関数内での switch-case 文により、現在の「状態」と「読み込んだシンボル」の組み合わせから次なる動作を一意に決定する、決定性チューリングマシンの挙動を忠実に再現。

メモリ初期化:

memset および strncpy を使用し、低レイヤでの安全なメモリセットアップを行っています。

💻 実行例
初期状態でテープに "111" を与えた場合、以下のように動作します。

開始状態: 111________________...

内部処理:

最初の 1 を x に置換。

State 1 に遷移し、テープの終端（空白）までヘッドを移動。

空白を検知して停止。

終了状態: x11________________...

📐 設計思想：思想工学的アプローチ
本コードは、すべてのソフトウェアの動作原理が「状態の遷移」と「記号の書き換え」に集約されることを示しています。複雑なシステムを最小単位まで分解し、その論理的な最小構成を記述する「自灯明」の精神、および「思考の工学化」を体現した非常に教育的な実装です。
